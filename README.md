# dd_portfolio

Personal portfolio for Ian Webster / Duskwood Design, served at [duskwood.design](https://duskwood.design) via GitHub Pages.

Built with Angular 14 as a single scrolling page: a home section and a grid of project cards.

## Adding a project

Add an entry to `PROJECTS` in [src/app/projects/projects.ts](src/app/projects/projects.ts) and drop its images in `src/assets/projects/`. Cards render in array order.

## Development

```sh
npm ci
npm start        # dev server at http://localhost:4200
npm test         # Karma unit tests (needs Chrome)
```

## Deploying

GitHub Pages serves the `docs/` folder on `main`.

```sh
npm run build    # production build into docs/, plus CNAME and 404.html
```

Then commit `docs/` and push.

## Brand assets

`src/assets/brand/` holds the Duskwood Design oak:

- `duskwood-mark.svg`: full-detail mark, for large uses (splash screens, the game).
- `duskwood-mark-small.svg`: the same tree with fine twigs pruned, for small sizes (nav).
- `duskwood-favicon.svg`: small mark on a dark tile.
- `duskwood-logo.svg`: stacked logo with the wordmark in Cinzel. The text is live and loads Cinzel from Google Fonts, so outline it (e.g. Inkscape: Path > Object to Path) before using it outside a browser.

All marks are one colour (`currentColor`, default `#64ffda`), so they can be recoloured. They're generated by `tools/duskwood-oak.py` (seed 5, depth 6):

```sh
python tools/duskwood-oak.py <seed> <depth> <out.svg> moon [min_twig_width] [ring_width]
```
